# GymFox — Fichier de préparation

## Description du projet

GymFox est un site web de commerce en ligne spécialisé dans la vente d'accessoires de gym et de musculation. Le projet cible les athlètes et amateurs de fitness qui cherchent des accessoires de qualité premium : sangles, ceintures, gants, bandes de résistance, genouillères, et plus encore.

Membre : zach belley

Le site permettra aux utilisateurs de :

- Parcourir les produits par catégorie
- Consulter les fiches produits détaillées (photos, description, tailles, prix)
- Ajouter des produits au panier et passer une commande

## Palette de couleurs

| Rôle               | Couleur    | Code hex  |
| ------------------ | ---------- | --------- |
| Couleur principale | Orange     | `#E65C00` |
| Fond clair         | Blanc      | `#FFFFFF` |
| Texte principal    | Noir       | `#111111` |
| Fond secondaire    | Gris clair | `#F5F5F5` |
| Texte secondaire   | Gris       | `#666666` |
| Bordures           | Gris léger | `#E0E0E0` |

### Logique des couleurs

- Le **noir et blanc** donnent un look moderne et premium
- L'**orange** (#E65C00) sert de couleur d'accent pour les boutons d'action, les prix et les éléments importants — il apporte énergie et dynamisme sans surcharger
- Le tout s'inspire des grandes marques sportives qui misent sur la sobriété avec une couleur accent forte

## Wireframes

Les wireframes couvrent les deux pages principales du site :

### Page d'accueil (Homepage)

- Barre de navigation : logo, liens de navigation, panier
- Section héro : accroche, sous-titre, boutons d'action, image principale
- Grille de catégories : 4 catégories principales avec icône
- Section produits populaires : grille de 3 produits avec image, nom et prix

### Page produit (Product Detail Page)

- Galerie d'images : image principale + miniatures
- Informations produit : nom, prix, badge nouveauté
- Sélecteur de taille
- Boutons : Ajouter au panier / Ajouter aux favoris
- Description du produit
